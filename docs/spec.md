# 场域合成站 规格

GTNH 2.9.0 正式版的附属 mod。术语见 `GLOSSARY.md`。

## 范围声明

只实现下面列出的功能，不做额外设计。第一版明确**不做**：范围可视化、容器黑白名单、无线/跨维度、独立的存取接口方块、自定义配置界面、独立的合成材料。

## 1. 场域合成站

- 5 个独立方块，对应 LV、MV、HV、EV、IV。
- 可像普通工作台一样使用（3×3 合成）。
- **场域范围**是以站为中心的立方体，半径按档位：

| 档位 | 半径（格） |
| --- | --- |
| LV | 3 |
| MV | 5 |
| HV | 8 |
| EV | 12 |
| IV | 16 |

- **邻近容器**：范围内带物品栏的方块。GT 方块只算输入/输出总线和缓冲箱；GT 机器内部正在加工的槽位和输入/输出仓都不算（2026-11-04 用户确认）。只识别已加载区块。

## 2. 合成与 IO 规则

1. 合成材料：先取玩家背包，不够再取邻近容器。
2. 成品：放入玩家背包。
3. 剩余物（如空桶）：先放玩家背包，放不下再放回邻近容器。
4. NEI "+" 按钮：从玩家背包和邻近容器自动填充 3×3 网格。

## 3. 物品清单

合成界面旁的面板。界面继承原版工作台（`ContainerWorkbench`、`GuiContainer`），不使用 ModularUI2（2026-11-04 用户要求，以兼容其他 mod）。

- 面板高度随屏幕变化，清单行数随之增减（最多 30 行）。滚动和搜索在客户端即时生效，每输入一个字立刻过滤。

- 列出所有邻近容器里的物品，可滚动，带名称搜索框（只按物品名称过滤）。
- 两种视图：**汇总视图**（同种物品合并）和**分容器视图**（按容器列出）。
- 操作：点击取一整组；右键取一半；Shift+点击放入玩家背包；用光标上的物品点击清单可存入；Shift+点击玩家背包里的物品直接存入。
- 汇总视图取出：按离站由近到远依次取。
- 汇总视图存入：优先已有该物品的容器，其次第一个放得下的容器。
- 分容器视图存入：只进选中的容器。
- 放不下的物品留在玩家光标上，不丢弃，不部分吞掉。

## 4. 供电

- 六个面都可接收 EU，无朝向。
- 放置后持续耗电（EU/t）：

| 档位 | 耗电 |
| --- | --- |
| LV | 30 |
| MV | 120 |
| HV | 480 |
| EV | 1920 |
| IV | 7680 |

- **断电**：降级为普通工作台，不识别邻近容器；物品清单面板变灰、不能操作；3×3 网格里的物品不丢失，结果槽按普通工作台重新计算；来电后自动恢复。

## 5. 合成配方

全部使用 GT 组装机，耗时 30 秒，耗电与对应档位的站耗电相同，焊锡 144L。各档独立合成，不需要上一档的场域合成站。

| 档位 | 配方 |
| --- | --- |
| LV | LV 机器外壳 + 4 个 MV 电路板 + 8 个镓板 + 9 根红石合金导线 |
| MV | MV 机器外壳 + 2 个 LV 力场发生器 + 8 个钽板 + 9 根 MV 超导线 |
| HV | HV 机器外壳 + 2 个 MV 力场发生器 + 8 个脉冲合金板 + 9 根 HV 超导线 |
| EV | EV 机器外壳 + 2 个 HV 力场发生器 + 8 个铟板 + 9 根 EV 超导线 |
| IV | IV 机器外壳 + 2 个 EV 力场发生器 + 8 个铈板 + 9 根 IV 超导线 |

本 mod 不新增任何合成材料。

## 6. 技术

- 基于 GTNH `ExampleMod1.7.10`（Minecraft 1.7.10、Forge、Gradle）。
- 依赖 GregTech、GTNHLib、NotEnoughItems，通过 Mixin 让 NEI 合成链统计全部邻近容器；依赖从 GTNH Maven 按实例中的版本下载，用于编译。
- modid `fieldcrafting`，包名 `com.rtgame.fieldcrafting`。
- 运行测试使用本地实例 `D:\mc\Prism-GTNH\instances\GTNH-2.9.0-RC-2`（实例名未改，内容已是正式版）：构建 jar 后用脚本复制到其 `.minecraft\mods`。
- 实例中的参考版本：gregtech 5.09.54.265、gtnhlib 0.11.54、NotEnoughItems 2.8.171-GTNH。
- 材质为程序生成的占位图（基于原版工作台贴图，按档位变色）；语言文件为简体中文和英文。

## 7. 待核实

实现前对照实例核实配方里的物品是否存在、名称是否一致，尤其是镓板、脉冲合金板、铈板、红石合金导线，以及各档超导线和力场发生器。有出入时回来确认，不自行替换。

### 核实结果（2026-11-03，GT 5.09.54.265）

- 脉冲合金板：中文「脉冲合金」对应 `Materials.VibrantAlloy`（`PulsatingIron` 的中文是「脉冲铁」），已与用户确认使用 VibrantAlloy。
- 红石合金导线：`wireGt01` + `Materials.RedstoneAlloy`（`RedAlloy` 中文是「红色合金」），已与用户确认。
- MV 电路板：使用矿辞 `circuitGood`（MV 优质电子电路，兼容各种基板制作的版本），已与用户确认。
- 超导线：`wireGt01` + `Materials.SuperconductorMV/HV/EV/IV`；力场发生器：`ItemList.Field_Generator_LV..EV`；机器外壳：`ItemList.Hull_LV..IV`；板：镓/钽/铟/铈使用对应 `Materials` 的 `plate`。
- 若运行时某材料取不到物品，会在日志输出「场域合成站 x 档配方材料缺失，已跳过」。

### 实现约定（2026-11-03，补充规格未写明的细节）

- 光标上有物品时，右键点击物品清单只存入 1 个，左键存入整组（与原版习惯一致）。
- 站只接收不高于本档电压的 EU，超压直接拒收（不爆炸）；内部缓冲为 4 个电流包（电压 × 4）。
- 合成只消耗网格里摆着的材料，用光的格子不自动补料，Shift+点击结果槽合到网格材料用完为止（2026-11-04 用户确认，见 ADR 0001 修订）。
- 邻近容器：GT 方块只认输入总线、输出总线、缓冲箱（并排除虚拟电路槽等无效槽位）；非 GT 的 `IInventory` 方块按面规则识别（`FieldScanner.SidedRules`）。
- 断电时站的行为与普通工作台一致，包括 Shift+点击背包物品（主物品栏与快捷栏之间移动）。
- 能看见但不能取出的物品（如关闭了自动输出的总线）在清单里单独成格，可见但不可取，也不计入合成可用材料。
- 成品去向保持现状：点击结果槽进光标，Shift+点击和 NEI 合成链进背包（2026-11-04 用户确认）。
- 合成网格左侧有快捷按钮：旋转；均分（Shift+点击为平铺到空格）；取回背包；放回邻近容器（按当前视图存入，断电时隐藏）。放不下的物品留在格子里（2026-11-04 用户提出）。
- 支持 NEI 合成链（用户后续提出的需求）。NEI 原本只统计槽位里的物品，这里用 Mixin 改为统计背包、网格和全部邻近容器，不受清单当前显示哪一屏影响。
