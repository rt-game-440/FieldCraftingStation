# 首版验收清单（2026-11-03）

以下项目需要在真实 GTNH 客户端里人工操作验收。代码已通过编译与 24 个单元测试（`FieldInventory` 规则），但界面、GT 电缆联动、NEI "+" 都没有在实机上跑过。

准备：`.\scripts\deploy.ps1 -SkipTests`（建议先把 `-ModsDir` 指向一个专用测试实例，不要用正在游玩的实例），新建创造模式世界。

## #3 五档场域合成站

- [ ] **创造标签页与方块外观**
  - 操作说明：打开创造物品栏「场域合成站」标签页，放置五档方块。
  - 预期效果：名称为「场域合成站（LV）」…「（IV）」；顶面有 3×3 网格线，侧面底部有对应电压颜色的色带，无紫黑贴图。
  - 用户反馈：
- [ ] **界面布局**
  - 操作说明：右键方块打开界面。
  - 预期效果：左侧搜索框 + 「汇总」「容器」按钮 + 9×8 物品网格；右侧标题、3×3 合成格、结果格、玩家背包；无控件重叠或超出面板。
  - 用户反馈：
- [ ] **六面接电**
  - 操作说明：用 LV 发电机/电缆分别从上下左右前后接入站（IV 站用对应电压）。
  - 预期效果：六个面都能供电；界面显示「供电正常」；超过本档电压会被拒收。
  - 用户反馈：
- [ ] **断电降级**
  - 操作说明：断开电源，等电量耗尽；摆好合成格里的材料。
  - 预期效果：站变成普通工作台，格子里的物品保留，结果槽立即按当前内容重新计算；邻近容器不参与。
  - 用户反馈：
- [ ] **普通工作台功能**
  - 操作说明：摆放工作台配方并取出成品；Shift+点击结果槽。
  - 预期效果：与原版工作台一致；剩余物（空桶等）进背包；用光的格子自动补同种材料（背包优先，其次邻近容器）。
  - 用户反馈：
- [ ] **识别范围**
  - 操作说明：在站旁分别 3/5/8/12/16 格处放箱子（对应 LV…IV）；并放一个 GT 输入总线/输出总线/缓冲箱。
  - 预期效果：范围内容器被识别，范围外不识别；总线的虚拟电路槽不计入物品。
  - 用户反馈：

## #4 物品清单面板

- [ ] **汇总视图与滚动、搜索**
  - 操作说明：箱子里放入很多种物品；用滚轮和滚动条滚动；在搜索框输入物品名（只按名称搜索）。
  - 预期效果：同种物品合并显示总数；滚动、搜索正常；鼠标悬停高亮与鼠标位置一致，悬停显示物品提示与数量。
  - 用户反馈：
- [ ] **取出**
  - 操作说明：点击一个物品、右键、Shift+点击。
  - 预期效果：点击取一整组到光标；右键取一半；Shift+点击直接进玩家背包；汇总视图按由近到远的顺序取。
  - 用户反馈：
- [ ] **存入**
  - 操作说明：光标拿着物品点击清单；Shift+点击背包里的物品。
  - 预期效果：汇总视图优先存入已有同种物品的容器；放不下的留在光标上。
  - 用户反馈：
- [ ] **分容器视图**
  - 操作说明：点「容器」按钮，用 `<` `>` 切换容器，取放物品。
  - 预期效果：只显示选中容器的内容，并显示名称/坐标/距离；存入只进选中容器。
  - 用户反馈：
- [ ] **断电变灰与自动恢复**
  - 操作说明：界面打开状态下断电，再恢复供电。
  - 预期效果：清单变灰、显示「电力不足」且不可操作；来电后自动恢复。
  - 用户反馈：

  - 用户反馈：

  - 预期效果：每档都能产出对应站。
