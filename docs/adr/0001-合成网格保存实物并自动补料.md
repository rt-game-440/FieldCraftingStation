# 0001 合成网格保存实物，取走成品后自动补料

状态：已采纳（2026-11-03）

## 背景

规格里写"合成材料先取玩家背包，不够再取邻近容器"。工作台的 3×3 网格在界面关闭后是否保留物品、取走成品后网格如何变化，规格没有明确。

## 决定

- 3×3 网格保存**实物**（存档，关闭界面后保留，拆除方块时掉落），行为与普通工作台一致。
- 取走成品时，按普通工作台规则消耗网格里的材料；被用光的格子再从**玩家背包优先、邻近容器其次**补充同种材料，这样连续合成不用反复摆放。
- 剩余物（空桶等）先放玩家背包，放不下放回邻近容器，仍放不下则掉落。
- 断电时邻近容器不参与：补料只用背包，行为等同普通工作台。
- 结果槽只用于界面，不存档。

## 备选

- 网格只做"虚拟配方"，所有材料在取成品时才从背包/容器扣除。放弃原因：与 NEI "+"、与普通工作台的肌肉记忆不一致，且容易出现"网格看着有材料却合不出来"的状态。

## 影响

- 单元测试覆盖 `FieldInventory.consumeMaterial` / `giveToPlayerOrField`；网格与界面联动需在实机验证（见 `docs/checklist`）。
